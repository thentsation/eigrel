# Security Policy

## Supported versions

Eigrel is pre-1.0. Only the latest release receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately through GitHub:
[Report a vulnerability](https://github.com/thentsation/eigrel/security/advisories/new).

Include a description of the issue, steps or an `.eig` file that reproduces it, and the impact you
expect. You should get a first response within 7 days. Once a fix is released, the advisory is
published with credit to the reporter unless you prefer to stay anonymous.
